# BakeryMLPManager
Bakery + MLP Swapper, this was a script i made in my game John's Basics to allow for Bakery Lighting & Magic Light Probes to be able to swap easily, i used this to change my lighting from Dark-Light-Red whenever needed, this proved useful as it allowed for optimisation on headsets hitting upwards of 90FPS on both the Quest 3 & 2. 

## How does it work?

Pretty simple i haven't used it in a long time but it takes in all the 3 types of lightmaps from Bakery (shadow,Light,rgb if im correct) and from MLP by taking in each probe into an array 

May come across as un-optimised but it works
